# Changelog

All notable player-facing gameplay changes should be recorded here.

## Unreleased

- Fixed reviewed gameplay edge cases: locked Rogue Eviscerate can no longer be cast, unresolved full-bag boss rewards on stairs no longer auto-exit the dungeon, empty offhands cannot be upgraded, and startup falls back to existing character saves when the profile is missing or stale.
- Improved Sorceress mana sustain: cheaper stronger mana potions, mana-potion hotkey fallback, and Arcane Recovery on kills.
- Increased Mana Shield's base damage redirection to 50% at rank 1, scaling to 70% by rank 5.
- Improved Sorceress defenses with stronger starter robe/focus stats, starting Mana Shield rank 1, and minimum small-hit shield absorption.
- Removed item attribute scaling; weapon damage no longer increases from Strength, Dexterity, or Intelligence.
- Added a searchable in-game help glossary opened with `h`/`H` from town or dungeon.
- Added this changelog so future gameplay changes have a dedicated place to be recorded.
